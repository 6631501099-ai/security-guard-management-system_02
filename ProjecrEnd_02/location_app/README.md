# location_app

A new Flutter project for real-time location tracking and emergency alert management.

## 📱 About This Project

This application was developed using Flutter and Firebase to help users share their live location and send emergency SOS alerts.  
The system includes both user and admin functionalities:

- Users can log in and send SOS alerts with their current GPS location.
- Admins can monitor alert locations in real time using Google Maps.
- Firebase Authentication is used for login and role management.
- Cloud Firestore stores user and SOS data securely.
- Google Maps API is integrated for live map visualization.

## ✨ Features

### 👤 User Features
- User registration and login
- Real-time GPS location detection
- Send SOS emergency alerts
- Store alert information in Firebase

### 🛡️ Admin Features
- Admin dashboard
- View all SOS alerts
- Real-time map monitoring
- Manage users and emergency requests

## 🛠️ Technologies Used

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Google Maps Flutter
- Geolocator
